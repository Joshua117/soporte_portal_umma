## Categoria

Este módulo es fundamental para el control y la integridad del inventario. Su función principal es clasificar los insumos entrantes según su naturaleza, asignándolos automáticamente al departamento o área correspondiente. Esta segmentación asegura que cada producto sea almacenado de manera adecuada, facilitando su identificación y gestión.

### Clasificación de Categorías
El sistema cuenta con categorías predefinidas, cada una diseñada para satisfacer las necesidades específicas de las diversas áreas de la institución. Además, el sistema ofrece la flexibilidad de agregar nuevas clasificaciones según sea necesario:

* **Equipos Electrónicos:** Dispositivos, hardware y componentes tecnológicos.
* **Gastronomía:** Insumos, utensilios y materiales relacionados con el área de alimentos.
* **Herramientas:** Equipos de trabajo manual o eléctrico para mantenimiento y construcción.
* **Limpieza:** Productos químicos y utensilios destinados al aseo y desinfección de instalaciones.
* **Materiales de Modas:** Insumos específicos para diseño, costura y confección.

### Propósito Estratégico
La implementación de este sistema de categorización responde a dos necesidades operativas críticas:

* **Prevención de Daños:** Al evitar que productos incompatibles se almacenen juntos (por ejemplo, previniendo la contaminación cruzada o riesgos físicos), se garantiza la integridad física de los materiales.
* **Optimización de Tiempos:** La estructura categorizada simplifica los procesos de búsqueda y auditoría, permitiendo al personal administrativo identificar rápidamente dónde se encuentra cada insumo dentro del edificio.

Al registrar un nuevo producto, el usuario debe seleccionar la categoría correspondiente; esto actúa como un filtro inteligente que dirige el producto a su ubicación óptima, garantizando que el inventario se mantenga organizado en todo momento.
