## Carga Académica

Este módulo permite gestionar y registrar la carga académica del periodo. Para crear una nueva carga, es necesario definir los parámetros que estructuran el servicio educativo, garantizando que la asignación sea precisa y organizada.

### Pasos para crear una Carga Académica

Para registrar correctamente una carga, deberás completar los siguientes campos en el sistema:

* **Ciclo Escolar:** Seleccionar el ciclo escolar que se está cursando actualmente.
* **Tipo de Carga:** Elegir la modalidad correspondiente (Materia o Taller).
* **Plan de Estudio:** Asignar el plan de estudio al que pertenece la carga.
* **Materia:** Seleccionar la asignatura que se va a impartir.
* **Grupo:** Definir el grupo al que irá dirigida esta carga académica.
* **Docente:** Asignar al profesor encargado de la materia.
* **Programación:** Definir los días de clase en los que se impartirá.
* **Salón:** Seleccionar el aula o espacio físico asignado.
* **Cupo:** Establecer la cantidad máxima de alumnos permitida para este ciclo.
* **Horario:** Configurar la hora de inicio y de finalización de la clase.

Una vez configurados todos estos puntos, el sistema permitirá guardar la carga académica, quedando activa y disponible para el ciclo seleccionado.
