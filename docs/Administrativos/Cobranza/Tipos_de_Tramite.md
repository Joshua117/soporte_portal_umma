Este módulo detalla la administración de los **tipos de trámites disponibles al agendar una cita**, permitiendo consultar el catálogo vigente, dar de alta nuevos conceptos y gestionar sus subtipos. El flujo combina una vista de listado con acciones de control y un formulario para registrar trámites y subtipos:

### Catálogo y Gestión de Trámites
Aquí podrás visualizar los conceptos registrados en el sistema y administrar su disponibilidad operativa:

- **Listado de Trámites:** Muestra el total de trámites registrados y cada concepto disponible (como inscripción, pago de parcialidad o reinscripción) junto con sus subtipos asociados.
- **Control y Acciones:** Incluye un indicador de **estado** por cada registro y los botones correspondientes para **editar** o **borrar** opciones existentes.

### Registro de Trámites y Subtipos
Permite incorporar nuevos conceptos al catálogo y estructurar sus variantes de atención de forma ordenada:

- **Alta de Nuevo Trámite:** Permite capturar el nombre del tipo de trámite (por ejemplo, inscripción o reinscripción) desde el campo principal para sumarlo a las opciones de citas.
- **Configuración de Subtipos y Guardado:** Incluye el apartado de **Subtipos del trámite** con un campo de texto y botón **`+`** para añadir uno o varios subtipos relacionados, finalizando con **Guardar** para confirmar o **Cancelar** para descartar los cambios.

> **Propósito del Módulo:** Mantener actualizado el catálogo de trámites y subtipos disponibles en el agendamiento de citas, asegurando opciones claras y administrables para la operación institucional.
