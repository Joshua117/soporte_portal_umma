Este módulo funciona como el centro de control para la organización académica del docente. Aquí podrás visualizar de manera clara y directa todos los horarios de clase que tienes asignados, permitiéndote tener un panorama completo de tus actividades diarias y semanales.

### Información de la Sesión
La interfaz está diseñada para que puedas identificar rápidamente la información esencial de cada sesión:

* **Materia:** El nombre de la asignatura que impartes.
* **Día y Fecha:** El momento específico en el que se llevará a cabo la clase.
* **Salón:** La ubicación física o el aula asignada para la sesión.
* **Grupo:** El grupo específico con el que tendrás la clase, permitiéndote preparar el material adecuado para cada uno.

El objetivo de este módulo es simplificar tu gestión docente, evitando confusiones y ayudándote a llegar a tiempo y bien preparado a cada una de tus sesiones.
